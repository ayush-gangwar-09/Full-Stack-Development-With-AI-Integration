What is List ?
A list is a collection of related items displayed in an organised and structured manner using HTML <li> list element.

There are three types of list 
 Ordered List <ol>
 Unordered list <ul>
 Description list <dl>

1) Ordered List 
An ordered list start with <ol> tag, The list items will be marked with numbers 
types - 
Default - 1, 2, 3, 4
A = A, B, C etc
a = a, b, c etc
I = I, II ,III, IV etc
i = i/ ii, iii, iv etc

2) Unorderd list
An unorderd list start with <ul> tag, The list items will be marked with bullet points, not numbers 
types -  
Default - filled circle 
disc - filled circle 
circle - hollow circle 
square - filled square 
none = remove bullets entirely

3) Description list 
Description list used for terms & thier description & it start with <dl> tag.

order - dl>dt>dd

<dl> = description list 
<dt> = description term
<dd> = description data


# Nested List
