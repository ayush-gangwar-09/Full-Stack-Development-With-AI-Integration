# What is a Table?

A table is a collection of cells. It has rows and columns.

In a table, there are two things:

1. **Cellspacing** - Distance between two cells.
2. **Cellpadding** - Distance between the content and the border.

### Table Tags

* `tr` → Table Row
* `th` → Table Heading
* `td` → Table Data

### Rowspan

When we merge two or more rows, it is known as **rowspan**.

### Colspan

When we merge two or more columns, it is known as **colspan**.

# Image Tag

The `<img>` tag is used to add an image to a web page.

The `<img>` tag is an **empty tag**, which means it does not have a closing tag.

### Syntax

```html
<img src="image.jpg" alt="Description of image">
```

### Important Attributes

* **src** → Specifies the path or URL of the image.
* **alt** → Provides alternative text for the image if the image cannot be displayed.

### Example

```html
<img src="photo.jpg" alt="My Photo">
```
