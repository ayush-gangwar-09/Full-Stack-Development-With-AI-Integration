# Web Development

Web development is the process of creating websites and web applications that can be accessed through the internet.

There are three types of web development:

1. Frontend
2. Backend
3. Full Stack Development (Frontend + Backend + Database + Deployment)

## Technology Used

### 1. Frontend

* HTML5
* CSS
* JavaScript
* React
* Bootstrap
* Tailwind CSS

### 2. Backend

* Spring Boot
* Node.js
* Express.js
* MongoDB
* MySQL

### 3. Full Stack

Combines both frontend and backend technologies.

---

## What is a Website?

A website is a collection of web pages. Every website has a unique URL.

Web pages can include:

* Home Page
* About Us
* Profile
* etc.

---

## How Websites Work?

When a user enters a website URL in a browser, the browser sends a request to the server where the website is hosted.

The server processes the request and sends back the requested webpage to the browser, which then displays it to the user.

---

## Frontend

Frontend development is a technology where users interact with the user interface of a website.

It includes:

* HTML
* CSS
* JavaScript
* React
* Bootstrap
* Tailwind CSS

---

## Backend

Backend development is a technology where the server-side of a website is developed.

It includes:

* Node.js
* Express.js
* MongoDB
* MySQL

---

## Libraries

Libraries are pre-written code that developers can change manually.

Examples:

* React
* Tailwind CSS
* Animate.css

---

## Frameworks

Frameworks are pre-written code that helps developers build web applications faster and more efficiently, where users cannot change the code manually.

Examples:

* Bootstrap
* Express.js
* Node.js

---

## VS Code

VS Code is a code editor that is used to write code, where users can edit, run, and debug the code.

It is free and open-source software.

---

## GitHub

GitHub is a cloud platform that is used to store and manage code repositories.

It allows developers to collaborate on projects.

---

## Git

Git is a version control system that allows developers to track changes in their codebase and collaborate with other developers.

It helps to manage different versions of code and resolve conflicts.

# HTML

HTML stands for HyperText Markup Language, which is used to make the structure of web pages.

Markup means we use tags to make the structure.

---

## Doctype

Doctype tells the browser which version of HTML we are using right now.

---

## Strong & Bold Tag

`<strong>` gives informative information (knowledgeable information) for our browser for making Search Engine Optimization.

`<b>` tag is used for making text bold.

---

## Empty Tag (Open Tag)

They are those tags which do not have a closing tag.

Examples:

* `<img>`
* `<meta>`
* `<br>`
* `<hr>`
* `<input>`

---

## Container (Close Tag)

They are those tags which have a closing tag.

Examples:

* `<table>`
* `<form>`
* `<nav>`
